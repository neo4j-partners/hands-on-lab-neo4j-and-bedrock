# Summary

## What You Learned

- **Amazon Bedrock** provides unified access to foundation models
- **AI Agents** can take actions, not just generate text
- **LangGraph** orchestrates agents as graphs of nodes and edges
- **Tools** let LLMs interact with external systems

## The Agent Loop

```
1. User asks a question
2. LLM reasons about what to do
3. LLM calls a tool
4. Tool returns result
5. LLM incorporates result
6. Repeat or respond
```
