# Lab 2: Aura Agents

## What You'll Build

An AI-powered agent that helps users analyze SEC 10-K filings by combining:

- **Semantic search** - Find content by meaning
- **Graph traversal** - Follow relationships
- **Natural language queries** - No Cypher required

## No Code Required

Aura Agents let you build conversational AI interfaces through a simple UI:

- Configure tools visually
- Test in the browser
- Deploy to an API endpoint
