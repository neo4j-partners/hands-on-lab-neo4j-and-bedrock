# What is an Aura Agent?

## No-Code GraphRAG

Aura Agents provide AI-powered conversational interfaces to your graph database.

**How It Works:**

1. User asks a natural language question
2. Agent selects the right tool for the job
3. Tool retrieves data from Neo4j
4. LLM synthesizes a human-readable response

## Why Agents Matter

- **Democratize access** to graph insights
- **Build chatbots** that understand your domain
- **Combine multiple retrieval patterns** automatically
