# Getting Your Credentials

## Step 1: Create API Key

1. Log in to [console.neo4j.io](https://console.neo4j.io)
2. Click your **profile icon** → **Settings**
3. Go to **API keys** tab
4. Click **Create API Key**
5. Save both **Client ID** and **Client Secret**

> **Important:** The Client Secret is only shown once!

## Step 2: Get Agent Endpoint

1. Navigate to your agent in Aura Console
2. Click **Copy endpoint**
3. URL format: `https://api.neo4j.io/v2beta1/.../invoke`

## Step 3: Enable External Access

Ensure **External endpoint** is enabled in agent settings.
