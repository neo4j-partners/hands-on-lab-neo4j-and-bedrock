# Lab Notebooks

## Four Hands-On Notebooks

| Notebook | Topic |
|----------|-------|
| **01_data_loading** | Create Document-Chunk graph structure |
| **02_embeddings** | Generate embeddings, create vector index |
| **03_vector_retriever** | Build basic GraphRAG pipeline |
| **04_vector_cypher_retriever** | Graph-enhanced retrieval |

## Progression

1. **Structure** - How to organize documents in a graph
2. **Embeddings** - Enable semantic search
3. **Basic RAG** - Vector search + LLM
4. **Enhanced RAG** - Add graph traversal for richer context

## Key Tools

- **FixedSizeSplitter** - Chunk text with overlap
- **BedrockEmbeddings** - Generate vectors with Amazon Titan
- **GraphRAG** - Orchestrate retriever + LLM
