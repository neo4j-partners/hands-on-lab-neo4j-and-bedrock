# Aura for AI/GenAI

## GraphRAG Foundation

Neo4j Aura provides unique capabilities for AI applications:

- **Store knowledge graphs** that power AI agents
- **Vector search** for semantic similarity
- **Graph traversal** for relationship reasoning

## Production-Ready Features

| Feature | Benefit |
|---------|---------|
| Vector indexes | Fast similarity search on embeddings |
| Cypher query language | Complex retrieval patterns |
| APIs | Integration with LLM frameworks |
| Graph algorithms | Built-in analytics (PageRank, community detection) |

## Integrated Tools

- **Query Workspace** - Write and execute Cypher queries
- **Explore** - Visual graph exploration (powered by Neo4j Bloom)
- **Dashboards** - Data visualization with low/no code
