# Lab Steps Overview

## Part 1: Neo4j Aura Signup

1. Subscribe via AWS Marketplace
2. Create your Aura account
3. Provision a database instance
4. Save your connection credentials

## Part 2: Restore the Backup

1. Download `finance_data.backup` from GitHub
2. Open your instance in the Aura Console
3. Upload the backup via **Backup & restore**
4. Wait for restore to complete

## Part 3: Explore the Graph

1. Open Neo4j Explore
2. Search for patterns between entities
3. Apply graph algorithms (Degree Centrality)
4. Identify key entities visually

## Part 4: Save Credentials

Update `CONFIG.txt` with your Neo4j connection details for later labs.
